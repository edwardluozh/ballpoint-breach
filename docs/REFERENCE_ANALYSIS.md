## 4. 角色卡

### 4.1 普通 NPC(雪人)
- **整体**:纸白填充、红笔轮廓的"雪人":一个不规整圆头 + 独立的、更宽的微变形圆肚;总高≈3.4×头径;肚宽≈1.14–1.20×头宽;腿段≈1.4×头径。
- **腿**:细长线段,红色断续笔触填充(不是实心);两只不匹配的纸白多边形角状鞋。
- **臂**:红色两段折线臂,端点为不规则纸白"手套"圆。
- **脸**:石墨眉/眼/鼻/嘴 + 一条细红眼线;表情因变体而异(npc_07"惊愕张嘴"、npc_09"平眉闭嘴")。
- **武器**:细长竖直枪形物持于脸与胸前,略倾斜、偏离中线;Marksman 持红色长枪(npc_09"红色长条武器+准星标记")。
- **变体**:≥8 个确定性外观变体(头/肚轮廓、脸、四肢长度角度、手套、鞋、武器姿势各不同)。
- **职业差异(玩法层)**:Grunt 常规;Rusher 快速近身;Heavy 慢速厚血(提示"the shotgun ends heavies");Marksman 远程红弹。

### 4.2 THE DOODLER(boss, wave 5)
- 纸白大圆身(同一雪人语言放大),**石墨色平顶 4–5 尖皇冠**(boss_12/18:头顶红色/双色冠饰),**愤怒红脸**,胸前横持**短奶油色铅笔**(boss_18/24:橙色长条+深色笔尖)。
- 动作:蓄力冲锋、铅笔横扫(橙色轨迹+纸屑)、拍击、投掷、召唤纸白小人、受击踉跄;半血进入更快的二阶段(boss_24 半血状态帧)。
- 顶部中央"THE DOODLER"血条:红填充+斜线纹理+靛蓝框。
